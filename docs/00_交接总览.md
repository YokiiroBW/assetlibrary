## 0.2 一句话产品定义

AssetLibrary 是一套面向自建 NAS 的跨端资产预览与管理系统：以真实物理目录为权威，用统一索引、跨格式预览、搜索、同步、整理、查重、Sidecar、角色资料和开发者接入增强文件管理，但不把资产锁进私有对象仓库。

## 0.3 核心产品形态

```text
资产库根
└─ 资源库分类
   └─ 专业模板
      └─ 具体资源库实例
         └─ 真实物理子目录
            └─ 真实文件
```

Windows Explorer 左侧只承担资源库分类、实例与真实目录导航；所有专业界面位于右侧内容区。Web 是完整管理控制面；Windows 独立客户端先承载并稳定右侧视图；Android/平板提供完整预览、相册与指定文件夹同步；浏览器扩展负责网络素材和网页剪藏。

## 0.5 当前不是最终实现的部分

以下内容在 M0 前仍是架构建议而非完成代码：

- Windows Explorer 自定义命名空间和右侧视图宿主的具体实现；
- AssetLink 的最终序列化和事件传输方案；
- 服务端最终语言/框架及 PostgreSQL 访问层；
- Provider 进程沙箱和资源限制的具体机制；
- UI 技术栈的最终选择；
- 首批在线元数据源的稳定性和合规验证。

这些必须通过技术验证和 ADR 正式冻结，不得由单个工作线程自行拍脑袋决定。
