## 0.2 一句话产品定义

AssetLibrary 是一套面向自建 NAS 的跨端资产预览与管理系统：以真实物理目录为权威，用统一索引、跨格式预览、搜索、同步、整理、查重、Sidecar、角色资料和开发者接入增强文件管理，但不把资产锁进私有对象仓库。

## 0.3 核心产品形态

```text
资产库根
└─ 资源库分类
   └─ 专业模板
      └─ 具体资源库实例
         └─ 真实物理子目录
            └─ 真实文件
```

Windows Explorer 左侧只承担资源库分类、实例与真实目录导航；所有专业界面位于右侧内容区。Web 是完整管理控制面；Windows 独立客户端先承载并稳定右侧视图；Android/平板提供完整预览、相册与指定文件夹同步；浏览器扩展负责网络素材和网页剪藏。

## 0.5 当前不是最终实现的部分

M0-009 已冻结技术族与依赖方向；V01-001 至 V01-014 提供组件基础，V01-015 至 V01-020 已将 HTTPS 认证、数据库、物理目录登记、首次扫描与 Web 浏览/搜索组成可运行的 Windows 只读试用。使用说明见 [只读试用交付](releases/READ_ONLY_TRIAL.md)。以下仍未形成正式产品能力：

- Windows Explorer 自定义命名空间和右侧视图宿主的具体实现；
- 预览、增量索引、完整管理控制面，以及公开/跨端部署和自动证书/升级生命周期；
- 耐久文件写入、完整同步、元数据、查重与产品级备份；
- Provider 进程沙箱和资源限制的具体机制；
- Windows、Android、浏览器扩展正式客户端与跨端验收；
- 首批在线元数据源的稳定性和合规验证。

当前完成度与后续顺序见 `releases/READ_ONLY_TRIAL.md` 和 `releases/V0.1_ALPHA_READINESS.md`；历史对齐记录见 `audits/2026-09-05-alignment.md`。未完成项继续由唯一 owner 按已冻结契约实施，不能自行改技术栈或解除门禁。
