## 大图操作

- 选中文件后Space、Enter或双击打开大图；左右键或上一张/下一张切换当前页文件。
- 滚轮以鼠标位置为中心缩放；左键拖动放大的图片。图像边界受限，不会拖到完全空白。
- 工具栏提供缩小、放大、适应窗口、预览100%；双击图片切换适应与100%。
- 键盘+/−缩放、0适应、1为100%；Shift+方向键平移。普通左右仍切图，Ctrl/Alt导航快捷键保留。
- 100%指当前派生预览的像素，不表示加载原件；显式缩放10%至400%。适应模式不自动放大小图。
- 调整窗口时，适应模式重算比例，显式缩放保留比例和图中位置；切图、失败、隐藏或关闭时复位。
- Esc/返回恢复原图片选择、焦点和图库滚动位置。缩放不增加图片请求，也不保存到浏览偏好。

原有保比例图库、列表切换、密度记忆、方向修正和透明图片继续可用。当前页最多100个普通项；原件打开/编辑、同步、全库连续滚动仍为后续工作。NAS同机图片服务已独立交付，见[NAS说明](NAS_IMAGE_PREVIEW.md)。
