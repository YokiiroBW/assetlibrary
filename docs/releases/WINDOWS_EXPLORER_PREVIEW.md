## 本版变化

- 上一页/下一页留在当前Explorer右侧，地址栏保持物理目录；NextPage主激活复用同一流程。
- 大图上一张/下一张支持跨页，左右键同样可用。每次最多跨一页；空页或只有目录时停在该浏览页并提示。
- 跨页先清旧图，缩放回适应窗口；Esc返回当前页并聚焦正在查看的文件。同页仍保留原选择与滚动恢复。
- 加载中Esc取消自动打开大图；较晚返回的自动预览不能覆盖新选择。错误可F5重试，权限/分页过期回资产库根。
- 原有保比例图库、列表、密度记忆、鼠标缩放/拖动、预览100%、键盘+/−/0/1与Shift+方向键平移保留。100%指派生预览像素。

## 验收

540安装文件逐项大小/强哈希匹配，新Explorer实际加载preview.9 DLL。120张合成图片分为100/20项；实测101→100→101、125%跨页后复位、102透明图及Esc选中、上一页重查、宽2311/窄923窗口、断开清图回根。258个合成源文件hash/mtime未变，临时Core/PG/6角色/HTTPS/runtime、测试Host/连接及两个自有窗口全部清理；原Explorer和Gallery/200偏好未动。

Shell13、图库受影响12、Setup23、发行锁16、包6、最终CLI8和图片夹具Python13/C#9通过。自动测试另覆盖失败重试、64位置上限/循环、晚到/隐藏/销毁、Esc与同generation重入。

## 保留边界

这一步仍是单页最多100项，尚未实现无限追加瀑布流。View只保留64个不含名称/图片的页位置，Host的64页/8192 token额度由所有窗口共享，到限会过期回根。每视图图片预算保持16MiB；超宽窗口同屏33项时部分缩略图会明确不可用，后续仍需优化显示尺寸与缓存调度。

Windows11旧底部计数以自有工具栏摘要为准；旧占用preview.1保留待清理，安装不强退Explorer。原件打开/编辑、同步、签名、人工认证/系统卸载UI、Android真机和完整V0.3仍独立。G1/G2/G3沿用已有实测，G4按用户要求豁免未执行；NAS部署未改。
