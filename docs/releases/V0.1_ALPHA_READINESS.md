# V0.1 Alpha readiness

**NAS Docker 服务端与第一版 Web 已交付，完整 V0.1 Alpha 发布仍为 blocked。** 使用入口见 [NAS Web](NAS_READ_ONLY_WEB.md)，[Windows 试用](READ_ONLY_TRIAL.md)继续保留。机器事实源为 `eng/v0.1-alpha-readiness.json`，实际 NAS 证据见 [V01-021](../../.codex/handoffs/V01-021/nas-deployment-evidence.json)。

```text
python -I -B scripts/validate_v0_1_alpha.py
python -I -B scripts/validate_v0_1_alpha.py --require-ready
```

默认审计返回 0 与 `ALPHA_INTEGRATION_AUDIT_OK decision=blocked`；要求完整发布就绪时返回 3。损坏政策或证据漂移返回 2，不能算正常阻断。

## 已交付的集成范围

Windows V01-015..020 与 NAS V01-021..023 复用同一核心和 Web：带外管理员初始化/恢复、持久密钥与会话、同源 HTTPS/CSRF、18 条 PostgreSQL 迁移及分模块最小权限连接、物理库登记、隔离 Worker 首次只读扫描、进度/取消/失败重试、目录浏览及名称/路径搜索。

NAS 实测包含登录→登记样例→扫描→浏览搜索、桌面/手机布局、Origin/CSRF 拒绝、非法 POSIX 路径失败关闭、重启后原会话和索引保留、管理员恢复撤销旧会话、资产哈希/mtime 不变。Core/PG 非 root、根文件系统只读、资产 bind mount 只读、PG 无宿主端口；独立验收项目的容器/网络/四卷回收后确认不存在。实际使用部署保持运行，图片/文档已登记但未开始全库扫描。

因此仅 Docker runtime capability 晋级为 `passed`，M0-004-G2 关闭，`docker-release` 环境门禁允许。认证、数据库、业务 Host 与 TLS/secret 仍为 `component_only`，V01-008 继续为 partial，输入用途仍为 adjudication_only；旧发行脚本生成的“本次未运行平台生命周期”报告不被改写为通过。NAS 新证据由 V01-021 单独负责。

## 完整 Alpha 仍缺少的能力

| 能力 | owner / 后续任务 | 当前缺口 |
| --- | --- | --- |
| 生产认证与公开部署 | gateway-auth-owner / V01-AUTH-RUNTIME | 已验收本地账号和 NAS LAN；公开互联网、多端/OIDC 仍待独立验收 |
| 全平台数据库与完整管理 Host | database-migration-owner / V01-DATABASE-RUNTIME；web-gateway-owner / V01-READ-HOST-INTEGRATION | 其他平台生命周期及完整管理功能未完成 |
| TLS、部署 secret 与更新 | server-packaging-owner / V01-TLS-SECRETS | 手动信任/续期；自动证书、升级和历史 Windows 异常终止密钥残留处理未闭环 |
| 标签、评分与颜色 | metadata-sidecar-owner / V01-METADATA-CORE | 共享写模型与审计用例未实现 |
| 精确查重 | search-dedup-owner / V01-DEDUP-CORE | 生产强哈希证据与权限过滤查询未实现 |
| 软件备份与恢复 | backup-update-owner / V01-BACKUP-RESTORE | 迁移备份/停机复制不能替代产品级备份、恢复和升级回滚 |
| 生产文件操作 | operation-trash-owner / V01-WRITE-DURABILITY-GATE | 耐久、恢复、锁/冲突/空间/校验/审计/垃圾桶的真实闭环仍缺失 |

预览、Provider、增量/通用重扫和完整客户端管理面仍未由本轮实现。首次扫描成功不代表实时同步。

`v0.1-release` 仍直接命中 M0-006-G1、M0-006-G2，且还有缺失能力和 V01-008 partial 输入。50 万资产长时运行与突然断电耐久性未获本轮证明。

下一步由用户选择既有路线中的后续里程碑，按唯一 owner 和冻结契约实施。只有全部能力、必需任务和 release targets 都满足后，才能声明完整 Alpha 就绪。
