# Web 工作区使用说明

此版补齐当前只读核心对应的页面和操作：从首页、分类、资源库进入真实目录，浏览和搜索文件信息，并管理资源库分类及首次扫描。NAS 地址和登录、证书说明仍见 [NAS 服务说明](NAS_READ_ONLY_WEB.md)。

## 页面与导航

- **首页**：查看可访问资源库，从八个分类入口进入相应列表。
- **资源库管理**：添加已配置存储范围内的资源库、修改分类、进入浏览或扫描管理。分类页标明聚合视图，修改分类不会移动原目录。
- **目录浏览**：面包屑可回到任意上级；双击目录或按 Enter 进入。浏览器前进、后退和刷新保留地址中的库、目录、查询、视图和打开的详情。当前会话还会恢复先前已浏览的列表位置。
- **扫描任务**：选择一个资源库，查看其实际扫描状态与计数，启动首次扫描、取消进行中任务或重试失败任务。页面关闭不会取消后台任务。

原有库升级后默认归为“通用”，管理员可以明确选择照片、图片、视频、音乐、工程、文档与阅读、角色或通用。系统不会根据库名推断类别。修改冲突时先刷新当前分类，再提交选择。

## 浏览、选择与详情

| 操作 | 行为 |
| --- | --- |
| 单击 | 选择条目；宽屏右侧显示文件信息 |
| Ctrl / ⌘ + 单击 | 添加或移除选择 |
| Shift + 单击 | 选择连续范围 |
| 方向键、Home / End | 在当前已加载列表内移动焦点或选择 |
| Enter / 双击 | 目录进入下一层，文件打开详情 |
| Esc | 取消选择或关闭当前对话框 |
| 列表 / 网格 | 切换展示方式，保留当前查询和选择 |
| 复制相对路径 | 复制所选条目的路径；跨库时每行用“库名 + 制表符 + 相对路径”标明归属 |

多选作用于已加载的条目，不冒充选中尚未读取的全部结果。剪贴板不可用时可从只读弹窗手动复制。此操作只复制文本，不接管原文件复制/剪切语义。

窄屏详情显示为可关闭的抽屉。详情页可“定位所在目录”，服务器直接返回包含目标条目的起始页，随后继续向后分页，不需要逐页寻找远处条目。离线库仍可显示已获授权的索引信息，并明确标记离线。

## 排序、筛选与搜索

目录可按名称、修改时间或大小升降序排列；目录等无大小值的条目排在大小排序末尾。类型和名称筛选会在服务端作用于整个目录，再返回有限页，点击“载入更多”继续读取同一范围。

“筛选当前目录名称”按文字包含匹配，`%`、`_` 等字符没有通配含义。顶部搜索按既有文件名/相对路径索引匹配，可选择全部授权库、当前库或当前目录及子目录；范围切换会保留来源目录。搜索词至少两个字符。

## 扫描与权限边界

新建库默认选择已配置的存储源根目录。需要其子目录时再展开高级输入，服务端仍检查真实路径、重叠和允许范围。登记和分类操作仅系统管理员可用；普通用户仍只看到被授权的资源库。

首次扫描完成后保留已提交快照。刷新只重新读取索引，不会扫描原目录或更新后来变化的文件。本版没有内容预览、原文件下载、通用/增量重扫、上传、改名、移动或删除；详情如实展示已有文件信息。

本次查询格式升级会使旧分页游标失效，刷新页面可从第一页恢复。更新部署保留原库、账号、密钥和已完成扫描；不会自动扫描尚未开始的文档库。退出或切换账号会清空旧查询和详情，地址或复制的路径本身不授予读取权限。
