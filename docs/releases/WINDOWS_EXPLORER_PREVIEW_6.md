# Windows 原生资源管理器图库浏览版

2026-09-13，`0.3.0-preview.6`，Windows 11 x64。图片在原生Explorer右侧内容区浏览；连接设置仍是辅助窗口，没有另开独立资产浏览客户端。本机已安装此版，测试账号已退出，测试连接配置已移除。

## 安装包

[下载本机安装包](../../.runtime/releases/windows/AssetLibrary-0.3.0-preview.6-win-x64.zip)，155482299字节（约148MiB）。源码：`03a95f9b90154c8594922c7b2ad0f49ac1521083`。

SHA256：`0e6a60d23fcaaa02f978ce816237f15930d801e0695bfbd837cb237d19be9810`。

完整解压，保留`payload`和`manifest.json`，运行`AssetLibrary.Setup.exe`。在连接设置中填写自己的HTTPS服务地址、账号和可信证书指纹，然后从资源管理器左侧“资产库”进入。记住登录默认关闭。安装包尚未签名，SHA256只证明文件完整性。

## 本轮新增

- 保留图片比例的行对齐瀑布流，图库/列表切换及图片大小调节。
- 中文目录和友好标签、键盘方向导航、连续多选、明确分页入口。
- 按可见范围分批加载缩略图，离开视图取消旧任务；不会只加载同屏前16张。
- 图库工具栏显示当前页和已选数量，窄窗口自动换行。
- 加载、空目录、权限或预览不可用状态；刷新、退出后清空旧图和选择。
- 原生辅助技术接口与有界退出清理，图片解码和网络仍在Explorer进程外。

## 实机与边界

最终安装包已在真实Explorer中连接隔离Core/PostgreSQL/HTTPS服务，验证JPG/PNG/WebP、方向修正、透明图片、目录/分页、100项与10项计数、多选、宽窄布局、滚动和退出清理。148个合成源文件的哈希与修改时间未变，临时服务/数据库角色/测试连接已清理；原Explorer没有重启。

**NAS现有图片服务限制仍在。** 本次图片来自本机真实隔离Core的派生结果，不代表NAS图片引擎已经启用；连接缺少预览能力的服务时会显示预览不可用。

- 本版提供当前页缩略图；双击大图、时间轴、全库连续滚动、上传/下载/同步及文件写入另行开发。
- 当前页最多100个普通项，另有分页导航；进入新目录后恢复默认图库和密度。
- 部分Windows11系统底部状态栏会保留旧视图计数，**以图库工具栏摘要为准**，不修改系统私有控件。
- 未自动填写认证表单或操作系统卸载界面；安装/卸载逻辑有真实EXE沙箱验证。旧preview.1占用版本仍列为待清理，未强删DLL。
- G1/G2/G3沿用实测证据；G4按用户要求豁免且未测试，完整V0.3、签名和Android真机门禁未因此关闭。
