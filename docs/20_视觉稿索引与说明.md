# 20. 视觉稿索引与说明

## 20.1 使用原则

视觉稿用于确认信息层级、布局边界和跨端感受，不作为逐像素最终UI规范。Windows稿中顶部与左侧代表原生Explorer外壳；真正自定义内容只在右侧。

## 20.5 后续视觉产出规则

- 只为视觉方向、架构、模块框架和关键交互生成图片；
- 长篇需求、数据模型、状态机和说明使用Markdown、表格或代码块；
- 视觉稿若与文字基线冲突，以文字基线与ADR为准；
- 最终UI组件需在独立客户端中验证后再嵌入Explorer。
