# 11. 专业资源库需求

## 11.1 照片库

- 文件夹、时间轴、地图、人物、相机、收藏；
- EXIF、RAW、实况照片、连拍、GPS、GPX；
- 同源与清晰度对比；
- 手机相册同步；
- 分享时移除/模糊位置；
- 人物识别默认关闭，本地空闲分析。

## 11.2 图片素材库

- 瀑布流、网格、颜色、尺寸、格式和透明筛选；
- PSD/RAW/EXR/HDR代理；
- 来源与授权；
- 图片同源和质量版本；
- 简单图片编辑与正式导出。

## 11.3 表情包库

属于图片分类的专业模板：

- 物理目录按角色、套装或来源组织；
- 情绪、语境、文字和用途使用逻辑标签；
- OCR、最近使用、常用、收藏、静态/动图；
- Android系统分享，Windows复制/拖拽；
- 平台兼容发送副本；
- Telegram贴纸同步可作为后续增强；
- 为未来自研输入法提供受限、版本化表情接口和离线缓存。

## 11.4 音乐库

- 专辑墙、艺术家、歌曲、文件夹；
- 进入专辑后大屏播放：左侧封面/黑胶，右侧歌词，底部控制条只占右侧内容区；
- 后台播放和跨端最近记录；
- 官方音乐元数据 Provider；
- 封面、LRC、CUE等伴随文件；
- 不做通用转码和复杂 DSP。

## 11.5 视频库

- 网格、代表帧、故事板、基础播放、倍速和续播；
- 时间码与片段标注；
- 不做影视刮削、复杂字幕、多音轨和剪辑；
- 不支持编码时使用临时代理或外部播放器。

## 11.6 文档与阅读

- PDF完整阅读、全文/OCR、非破坏标注；
- Markdown、TXT、配置和代码简单编辑；
- Office只读预览；
- EPUB、MOBI、AZW3基础阅读；
- CBZ、CBR漫画阅读；
- 官方电子书和网络小说元数据增强。

## 11.7 文本簿与网页剪藏

浏览器扩展支持：

- 选中文字保存为真实 Markdown；
- 正文提取为 Markdown；
- MHTML快照；
- 可见区域和框选截图；
- 长截图与组合剪藏作为增强；
- 页面标题、来源、站点、时间和作者候选；
- HTML/MHTML安全静态预览。

不采集浏览历史、Cookies、表单、书签和剪贴板。

## 11.8 工程与 3D

- 工程库为混合物理目录；
- GLB/GLTF/OBJ/STL等通用3D交互预览和视角书签；
- FBX等可选代理；
- DWG/DXF、MAX/C4D/SKP首期基础索引、伴随预览和专业打开；
- 不做项目依赖打包和交付快照。

## 11.9 角色库

每个角色是一个真实文件夹：

```text
角色档案.md
设定/*.md
设定草稿/
相册/
日记/
视觉/
语音/
视频/
模型/
```

总览使用大尺寸、精心设计的学生证/身份证式角色卡片。固定页签：总览、人设、相册、日记、关系、全部资产、联动。

人设采用核心档案 + 模块化 Markdown。正式设定与草稿物理分开。AstrBot只读取用户明确发布的 confirmed 模块，可提交日记草稿和待确认建议，不能直接改正式人设。
