# 18. 已砍除、明确不做与延期清单

## 18.1 已彻底砍除

- Komga集成；电子书和漫画只做普通资产预览。
- 项目依赖自动收集、自包含交付副本、交付快照和归档打包。
- DWG首期内置预览。
- 通过数据库逻辑文件夹代替物理目录。
- 软件自身备份资产原文件。
- 资产转换为只有本软件能读的私有加密格式。
- 多人实时批注、评论链、审批和工单平台。
- 完整影视媒体刮削、字幕管理和媒体服务器能力。
- 通用音视频正式转码器。
- 专业图片编辑、RAW显影、图层编辑和复杂滤镜。
- 远程聊天命令直接永久删除或静默移动资产。

## 18.2 V1.0 不阻塞 / 后续评估

- macOS客户端、Finder集成和macOS服务端。
- ARM64完整Provider覆盖。
- 多服务端联邦和多主写入。
- 公共插件市场。
- 小米云相册直接Connector。
- 把NAS注册为HyperOS系统云备份服务。
- 完整自研输入法本体；只预留表情接口。
- QQ/微信原生收藏表情自动同步。
- DWG、MAX、C4D、SKP原生渲染。
- 所有网络小说平台Provider。
- 完整Codex app-server项目指挥台。
- 高级3D编辑、网格修复和CAD编辑。
- 网页整站镜像、WARC和通用爬虫。

## 18.3 不能偷偷重新加入

任何工作线程发现这些范围“顺手能做”也不能自行实现。确需重新纳入，必须更新需求基线、ADR、版本路线和验收成本，由主协调线程审批。

## 18.4 原生浏览首版的后续范围

ADR-0017 的 V03-001..003 仅提前交付已有核心支持的原生浏览入口。
内容预览/缩略图、设备配对与持久设备凭证、自动主备切换、后台同步与移动归档、
长期同步后台任务和 URI 激活仍按完整 V0.3 路线后续实现；未砍除这些既定目标。
用户同日明确要求 Windows 首版以原生 Explorer 为入口，ADR-0018 已据此启动实际嵌入验证；
进程外 AssetHost 的必要只读 IPC 属于本轮。完整 Explorer 发行/稳定性仍须通过 V0.5 门禁，
生产写入仍须先关闭相应门禁。
