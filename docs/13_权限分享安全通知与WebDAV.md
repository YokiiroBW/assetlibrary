# 13. 权限、分享、安全、通知与 WebDAV

## 13.1 简单权限

用户界面只维护系统管理员、普通用户和按资源库权限档位。不做复杂逐文件 ACL。局域网也需要登录，但普通浏览不频繁弹确认。

## 13.2 分享

三种模式：

- 发送安全预览副本；
- 发送原文件；
- 生成限时 HTTPS 分享链接。

Android长按多选后调用系统 Sharesheet，可发送到 QQ、微信、Telegram等。原文件按需下载到受控临时缓存，通过只读 URI 交给目标应用。大文件和多文件优先限时链接。

分享可设置有效期、密码、预览/下载、访问次数和撤销。默认不暴露 NAS 绝对路径、GPS和敏感正文。

## 13.3 入站安全

所有新文件做签名、MIME、结构、可读性和稳定性检查。官方可选安全 Provider 对浏览器、Web/API/WebDAV、压缩包、Office、脚本、可执行文件和未知高风险内容做本地扫描。

默认“入站防护”。可疑内容进入传输中心“安全待处理”，不自动删除。

## 13.4 通知路由

基础站内通知，首批外部渠道：

- 通用 Webhook；
- Synology Chat Incoming Webhook；
- Telegram Bot；
- OneBot。

同类型可创建多个实例。按事件类别、级别、资源库、设备、成功/失败和时间段路由。聚合、去重、限流、重试和熔断。首版只做单向通知，不通过聊天回复执行文件管理。

## 13.5 凭证

用户会话、设备凭证、WebDAV应用密码、Developer API Token、MCP服务凭证、分享令牌和外部服务密钥分离。用户界面保持简单，但凭证可按资源库、能力、通道、流量、有效期和来源限制。

## 13.6 安全日志

日志不得保存密码、Token、Webhook Secret、完整 OCR、输入法输入、聊天内容或私密角色正文。诊断包默认匿名化真实路径并排除资产和缩略图。
