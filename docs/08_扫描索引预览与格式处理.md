# 08. 扫描、索引、预览与格式处理

## 8.1 首次建库

创建前预检路径、权限、重叠、规模、容量、格式分布和 Windows 兼容性。首次扫描只读：不移动、改名、删除、写回、创建 `.assetmeta` 或清理重复。

初始化阶段：

```text
目录与文件发现
→ 基础格式和元数据
→ 首屏/近期缩略图
→ 全库缩略图
→ 标准预览
→ 完整哈希、OCR、同源、人物与AI增强
```

基础索引完成后即可使用，不等待所有增强任务。

## 8.2 日常变化

- NAS 本地或挂载目录实时事件；
- 去抖与批次聚合；
- 定期轻量核对；
- 用户手动完整扫描。

批量目录移动优先识别为目录级变化。事件丢失时用指纹/哈希修复。

## 8.3 忽略和特殊文件

默认排除系统、回收、缓存和临时文件。每库可追加 Glob、路径、隐藏属性、大小和类型规则，启用前模拟影响。

符号链接和目录联接只识别不递归；`.lnk` 只作为快捷方式；硬链接按同一物理内容多个入口处理。

## 8.4 预览缓存

缓存分：缩略图、标准预览、重型/交互缓存、临时缓存。内容哈希 + Provider + 版本 + 规格确定缓存身份。改名/移动复用，内容变化失效。

每库支持轻量、标准、完整和自定义档位，默认标准。Windows/Android只保存近期轻量离线预览，不做原文件离线同步。

## 8.5 安全预览

HTML/MHTML、SVG、PDF、Office、Markdown 的内置预览均视为不可信内容，禁脚本、宏、表单、外部请求、Service Worker 和危险嵌入。

## 8.6 色彩与 HDR

读取 ICC、色彩空间、位深、Alpha、HDR和CMYK。默认自动色彩管理；分享预览转换为通用兼容色彩。RAW 区分内嵌 JPEG 与解码代理；PSD、CMYK和HDR明确提示代理差异。

## 8.7 图片轻编辑

仅支持裁剪、旋转/翻转、文字、自由线、箭头、框、高亮和马赛克。保存时生成新文件、新资产 ID 和系统见证衍生关系。RAW/PSD/HDR基于显示代理导出普通图片，原文件不动。

## 8.8 复合资产

- 强绑定：实况照片、RAW+强绑定XMP、OBJ+明确引用；默认一张卡片、整组安全操作。
- 普通关联：RAW+JPEG、PSD+导出图、MAX+GLB；只分组提示，不默认联动物理操作。
- 连拍/序列：折叠浏览、代表图、对比和选片，每张仍独立。

## 8.9 预览失败降级

任何 Provider 失败均至少保留 L0：文件名、路径、大小、哈希、标签、历史和外部打开。单个损坏文件不能阻塞资源库。
