# ADR-0016 — Web 产品交互与授权浏览查询

状态：Accepted for implementation，2026-09-08。Owner V01-024；Web V01-025，支撑查询 V01-026。

## 问题与交付范围

V01-021 已完成真实 NAS 部署和最小只读链路，V01-023 仅调整了路径/状态文案；这不代表 docs02/04/12 与10_web设计图的产品交互已经完成。用户要求先完善 Web。本轮以用户操作验收：首页 → 分类/库 → 物理目录 → 资产L0详情；导航能前进/后退、刷新和通过链接恢复；库分类、扫描任务、选择、排序筛选、搜索范围与移动端详情都有实际行为。

复用冻结的React/TypeScript与现有SDK、请求/会话管理和虚拟化。采用浏览器History API以及有限的服务端SPA入口，不新增路由框架或第二服务。URL仅记录相对路径、稳定ID与有限展示/查询选项；不记录凭据、绝对根路径或大批选择。权限失效与换身份仍清空旧数据。

管理页只呈现当前核心已有且可操作的库/首次扫描管理。任务页明确以选定资源库为范围，不通过无限并行请求伪造全局任务统计。没有真实摘要的资产总数和容量不伪造。文件打开进入已提交索引的L0详情；本轮不跨入V0.3的实际内容预览或开启仍受门禁约束的文件写入。

## 必要的核心支持

完整分类页和目录排序不能对前端已加载的100项局部处理后宣称全库结果。按 [Web interaction v1](../../contracts/assetlink/web-interaction-v1.md) 追加现有模块的授权查询和显式分类元数据：分类筛选、单库/单条详情、全目录排序/类型及名称过滤、锚点定位、授权库/子树搜索。排序游标绑定所有影响结果的选项，权限在每页重验。

LibraryStorage拥有分类（8个冻结分类，旧库general）与系统管理员CAS/幂等更新；AssetIdentity拥有条目排序/筛选查询和索引；GatewayAuth拥有权限过滤的批准只读投影和协议适配。不跨模块写表，不把权限/路径业务搬进Web。单一SQL写者V01-026分别追加0019、0020、0021三个按模块owner执行的迁移，不混合SET ROLE或修改历史迁移。

存储源允许根只向系统管理员作为默认登记选项返回，子目录保留高级输入；核心继续执行物理probe与路径边界。没有任意服务器目录枚举和匿名初始化入口。

## 性能、兼容和交付

500k资产下沿用有限页、稳定keyset cursor和现有全文/路径索引，增加与实际排序相符的索引；不得全库拉取后在浏览器排序或无限翻页定位。旧调用省略新增选项时保持默认；不改变生成SDK envelope、Cookie/CSRF或模块角色。SQL新函数与旧签名并存；Host的精确迁移就绪要求保持不变。

集中实现后统一审查和验收：现有受影响Web与后端回归、必要真实PostgreSQL分页/权限/迁移，以及实际NAS首页/导航/详情/扫描界面操作。先备份现有配置与持久卷再更新，保留不可变旧包和匹配数据库的回退说明；不自动扫描个人图片/文档，不重建管理员。保持Git主线同步与工作区干净。

完整Alpha、预览、增量重扫、生产写入和其他平台门禁仍独立；本轮结束应精确描述已完成的Web交互，不再把最小接口验证界面概括为完整Web产品。
