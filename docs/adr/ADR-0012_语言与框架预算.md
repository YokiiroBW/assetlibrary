# ADR-0012：每个平台实行语言与框架预算

状态：Accepted / Frozen by M0-009（2026-09-03）

决定：每个平台只保留一个主语言与主框架：

- 服务端、Worker 和三种 Host：C# 14、.NET 10 LTS、ASP.NET Core 10；
- PostgreSQL 16.x 是唯一数据库、基础搜索、任务租约和 outbox 底座；
- Web：Node.js 24 LTS 构建、TypeScript 6.0.x、React 19.2.x；
- Windows 独立客户端/AssetHost：C# 14、.NET 10、WinUI 3 / Windows App SDK 2.x stable；
- Windows Shell：C++17、Windows SDK 10.0.26100、COM/C++/WinRT，仅最小桥接；
- Android：Kotlin 2.3.x、Jetpack Compose stable BOM、AGP 9.x；
- Chromium 扩展：TypeScript 6.0.x、Manifest V3；
- 工具与生成：Python 3.12+，标准库优先。

M0-004、M0-005 和 M0-002 分别为 .NET 10 宿主、PostgreSQL 16.15、Windows C++/SDK 的 Spike 证据。Web、Windows UI 和 Android 是预算级选择而非可运行 M0 证据；首个生产清单必须固定精确补丁、依赖锁/验证文件，并在同一变更激活平台原生质量门禁。

替代方案：未选择 Node/Go/Rust 第二服务端、Electron/第二桌面框架、Java Android 业务栈、第二数据库、Redis 或独立搜索/消息集群，因为当前证据没有证明其必要性，且会增加发布矩阵和一致性成本。若真实指标持续超预算，必须用新 ADR 说明收益、迁移和退出路径。

升级与退出：同一冻结版本线内的安全补丁经完整 CI 可升级；minor/major、框架替换或第二基础设施必须提交 ADR，说明必要性、维护成本、许可证、安全更新、跨平台、体积、数据/协议迁移、回退和移除策略。精确版本以仓库清单和锁文件为准，不能依赖 CI runner 的浮动预装版本。

后果：语言预算由 `tests/architecture/architecture-rules.json` 阻断执行。尚未创建产品源文件的目录报告 inactive/not-applicable，不据此声称平台已验证。详细证据和版本激活条件见 `docs/23_M0架构冻结与质量门禁.md`。
