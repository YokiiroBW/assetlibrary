# ADR-0017 — Windows 与 Android 原生客户端首版

状态：Accepted for implementation，2026-09-08。用户明确要求继续开发 Windows、Android 第一版客户端，并按既有视觉和架构实现。V03-001 为协调与共享契约 owner，V03-002 为 Windows owner，V03-003 为 Android owner。

## 交付范围与路线

在已交付 V01-024..026 只读核心之上建立两个真正原生客户端：Windows 11 x64 的 C#14/.NET10/WinUI3、Android11+ 的 Kotlin2.3/Compose 手机和平板同一应用。此项是 V0.3 原生浏览预备交付，不宣告 V0.1 Alpha 或完整 V0.3 完成，不改变任何文件写入、Explorer 或 Provider 门禁。

可用闭环为配置 HTTPS 服务器、登录/退出、资源库首页与显式分类、真实目录导航与历史、列表/网格、分页排序/筛选、限定范围搜索、单资产文件信息和定位。使用服务端已存在的授权查询，管理操作仍由 Web 控制面负责。未授权与会话变化必须清空数据；断线保留的结果必须明确标记旧快照且允许重试/取消。不展示伪造统计、缩略图或不存在的同步/文件写入能力。

当前服务端没有生产握手、设备配对、内容下载/预览和同步端点；本次不把协议草案误当作运行能力。单 HTTPS 源档案是首版实际连接范围，自动主备切换待稳定 server_id 和多 Origin 的生产握手契约闭环后实现。未来完整 V0.3 的预览、分享、主备链接、同步与移动归档目标不删除。

## 原生会话适配

批准复用 `read-only-trial-v1.md` 的既有 HTTPS Cookie/CSRF 会话，在每个平台 HTTP 适配器中发送精确 endpoint Origin、同源 Cookie 和内存 CSRF。此复用不削弱服务端检查、不增加 CORS、Bearer、设备凭证或数据库访问。生成 SDK 继续拥有消息 envelope；open operation body 由平台的明确响应类型解析与请求关联校验。

服务器地址只能是无 userinfo/query/fragment/path 的 HTTPS origin。禁止自动跨源重定向和把凭据发给新来源；更换地址必须销毁旧会话、查询、历史与详情。密码仅用于当前登录且不写配置/日志。首版会话仅进程内保存，关闭应用后重新登录，非敏感服务器档案可持久保存。

默认使用系统 TLS 验证。NAS 自签证书只允许用户显式配置精确叶证书 SHA256 指纹，固定在单个 HTTPS origin；正常主机名与有效期验证仍必需，禁止信任全部证书、全局关闭 TLS、自动信任首次遇到的证书或静默接受换证。TLS 信任失败必须在发送账号/密码之前终止。日志仅含安全错误码/请求关联信息。退出失败不得显示服务端撤销成功，可明确执行本机清除。

## 原生布局与共享视觉

按 docs04/12/20 和 assets/visuals/01、02、08、09 确认的信息层级实现。Windows 的专业右侧区域先在独立客户端稳定，不创建 Explorer 扩展。桌面/平板宽屏为库导航、虚拟化内容、右侧详情；窄窗口/手机以切库、主内容、详情抽屉/面板重排。手机保留可用的底部导航，未实现功能不占据假入口。保留浅深色、键盘焦点、系统字体缩放、可访问名称和触摸目标。

以现有 Web 的语义颜色 CSS 为权威，由 `scripts/export_native_theme.py` 导出 `packages/ui/workspace-theme.json`；原生 UI 读取同一生成资源，禁止手工维护第二套颜色值。平台控件、窗口生命周期和触摸/键鼠行为保持原生。此小规模主题共享不引入额外 UI 框架。

## 构建与安全、性能证据

首个清单固定实际可取得的 stable patch，保留 NuGet lock、Gradle wrapper 校验/依赖锁及 strict verification。Windows 平台 solution 与跨平台核心 solution 分离；Android 直接编译原有 Kotlin 生成 SDK 源文件，避免把 JVM21 编译产物硬塞给 Android 或手改生成源。新增依赖必须记录许可证、更新、体积与退出方案。

50 万资产下只发出有界页请求、服务端全范围排序/筛选及现有索引查询；界面虚拟化且客户端保留条目数有明确上限，不拉取全库。搜索/切页取消旧请求，旧响应不能覆盖新身份或导航。实际构建和原生运行证据区分单元、HTTP 协议、UI、模拟器/实机与真实服务端；缺失设备、证书、签名或硬件证据如实记录，不记为通过。

交付可审查代码、Windows 试用包和 Android APK（试用签名明确标识），集中完成针对性验证及平台门禁。只在隔离样例上进行写型测试，不扫描或修改真实 NAS 资产；本轮不更新 NAS 服务端。
