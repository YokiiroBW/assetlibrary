# ADR-0025 — Explorer 页内翻页与跨页预览

- 状态：Accepted，V03-033 协调线程批准，2026-09-13。
- 依据：用户继续完善 Windows 浏览体验；ADR-0021/0022/0024。

## 决策

图库/列表的上一页、下一页在同一个原生 IShellView 内切换，不增加“下一页”地址栏层级。原有 NextPage 项的主激活使用同一流程。物理目录仍通过既有 Shell 导航。兼容 DefView、解析名称及上下文菜单的既有 NextPage PIDL，不更改 wire/PIDL/AssetLink 契约或 Core 排序。

这一步交付有界的页内浏览与跨页切图，不宣称无限追加瀑布流。当前页仍最多 100 项加一个导航项；只保留当前页名称、选择、可访问对象和像素。View 最多保留 64 个不含名称/路径的 epoch/node 页位置，用于回查前页；前页再次通过现有 Requests 查询，不把已显示内容当作当前权限依据。Host 的 64 页、8192 token、成功快照 5 秒有效期、过期回根及 HTTP 并发限制不变。达到本地历史上限不追加无界状态；明确提示重新打开目录，不冒充已到库尾。

切页先清旧图与选择，取消旧请求，以独立 generation 接收结果。成功才提交分页位置，错误可 F5 重试；旧结果、会话变更、隐藏、销毁不能复活内容。权限撤销/epoch 变化立即清历史和当前内容，复用现有回根。分页历史不写注册表、不持久化；50 万资产下单次工作仍 O(101)，页位置空间 O(64)，像素预算仍每视图 16 MiB。

大图上一张/下一张在本页边界可读取相邻页并打开该页最后/第一个普通文件；一次操作最多读一页，不自动穿过任意多空页或目录页。无普通文件时回到已加载的浏览页，显示明确提示。跨页时清旧图、缩放回适应窗口；Esc 返回当前页并聚焦当前文件。同页预览沿用原选择/滚动恢复。加载/错误期间不保留旧图片或虚假的全库计数。

Surface 只新增两个原生浏览按钮（114/115）、`pageStep(context, delta)` 回调与 `SetPageNavigation(previousEnabled,nextEnabled)` 展示接口；View 决定授权位置及按钮可用性。按钮参与 Tab 顺序、窄窗换行、高对比/焦点和禁用状态，预览时隐藏，回调重入遵守原生命周期约定。SetPage/Clear/隐藏退休可用标志，由 View 发布当前状态后恢复。

## 所有权与验证

V03-034 独占 View.cpp 与 GalleryViewTests.cpp；V03-035 独占 Surface.cpp 与 tests/windows-gallery 下既有测试。V03-033 独占冻结头、ADR、任务登记、版本/锁/发行文档与集成验收。需要新增共享接口先提交协调裁决。

验证同视图 HWND/导航次数不变、往返再次查询、失败重试、快速切页/晚到/权限/隐藏清理、页尾跨图、目录页停止、历史容量与循环 token、原缩放无新增 I/O、原生控件键盘/宽窄。发布和真实 Explorer 验收必须单独记录实际结果，G4 继续用户豁免，不宣称完整 V0.3。
