# ADR-0024 — Explorer 预览缩放与平移

- 状态：Accepted for implementation，V03-030协调；2026-09-13用户要求继续完善浏览体验。
- 在ADR-0022已有预览内推进，Windows入口继续原生Explorer右侧，不打开独立资产客户端。

## 行为

当前已授权1600派生预览增加滚轮缩放、左键拖动、适应窗口和100%按钮。普通滚轮或Ctrl+滚轮按每120刻度1.25倍率以鼠标位置为锚点；碎片刻度累计、零刻度不改变状态。Alt组合交给宿主。+/−及小键盘对应键以画布中心缩放；0适应、1为100%；Shift+方向键平移。普通左右键保留上一张/下一张，Ctrl/Alt导航快捷键不拦截。双击预览在适应与100%间切换，工具栏提供全部基本操作的键盘替代。

适应模式按图片与画布比例显示并不自动放大低分辨率图片；100%指当前派生预览的1像素对应1画布设备像素，不表示请求原件。显式缩放10%..400%，适应模式允许更小比例。状态摘要显示模式/百分比，保留当前图片状态和尺寸说明，不能让用户误以为提高了原件清晰度。

图片超过视口才允许对应轴移动，边界不露出不必要空白；较小轴居中。缩放尽量保持锚点，达到边界时按可见约束夹取。改变窗口/DPI后适应模式重算；显式模式保留比例与归一化中心，再夹取。计算遇到空/负视口、无效尺寸、NaN/无穷或极端输入时返回无操作/安全空状态。

切图、Begin/EndPreview、失败、隐藏、导航、权限失效、刷新、销毁立即复位缩放并终止拖动，旧图不复现。捕获丢失、CancelMode、失焦也终止拖动；所有系统callout后须检查Alive及预览代次。关闭预览保留既有选择/焦点/图库滚动恢复。缩放与拖动不发起新的IPC/HTTP、解码或偏好写入；不跨图片/会话保存。

## 边界与复用

沿用Surface、原生BUTTON/STATIC/GDI、现有UIA/MSAA与View请求所有权。PreviewViewport只保存少量数值状态，提供不分配像素的几何计算，由Surface与测试消费；共享头由root单一所有，实施方不得发明不兼容接口。

保持现有单张1600PBGRA、16MiB持久容量及最大10,240,000B源DIB。仅改变绘制目标矩形并裁剪到图片区域，禁止按缩放后尺寸创建位图、重解码或保存第二份放大像素。图库thumbnail绘制与预算不变。变换O(1)、切图仍限当前101项；50万资产不增加全库工作。无新依赖、框架、服务端契约、数据库或原文件写入。

验收须覆盖几何锚点/边界/DPI、真实HWND缩放与拖动/捕获取消/迟到/权限清理、UIA原生按钮及旧代理退役、实际GDI像素裁剪与资源稳定；最终真实Core→Host→Explorer仍需实测。G4沿用用户豁免，不安排20轮/8小时，不宣布完整V0.3。
