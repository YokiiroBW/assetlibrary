# 04. 客户端、平台与连接模式

## 4.1 产品端职责

### Web

完整管理控制面，并提供资产浏览。负责资源库、用户权限、任务、传输、整理、查重、Provider、缓存、备份、更新、健康、通知和开发者接入。

### Windows 独立客户端

先承载并稳定所有右侧专业视图，负责桌面浏览、预览、音乐后台播放、外部软件打开、文件夹同步、离线缓存和 Explorer 故障备用。

### Windows Explorer

最终日常主入口。顶部、地址栏、搜索和左栏保持 Windows 原生；自定义专业内容严格限制在右侧。Shell DLL 只做命名空间、导航、菜单和本机 IPC。

普通目录仅增加单一顶级右键入口：

```text
资产库 >
```

二级菜单按是否入库、对象类型、数量、权限和网络状态动态显示。

### Android / 平板

同一响应式应用。手机采用顶部切库、主内容、底部导航和详情抽屉；平板采用左侧库、中央内容、右侧详情。支持完整预览、相册同步、指定文件夹同步、系统分享和轻量整理。

### 浏览器扩展

首发 Chromium Manifest V3。负责网页图片、文件、选中文字、网页正文、MHTML、可见/选区截图和来源信息入库。

## 4.2 服务端发行

- Docker / Compose：NAS 与群晖推荐；
- Windows x64 原生：EXE + Windows Service；
- Linux x86-64 原生：直接运行 + systemd；
- 三种发行共用同一核心、数据库、协议、Provider和备份格式；
- macOS 首期不支持。

## 4.3 主链接与备用链接

每个服务器档案至少支持：

```text
主链接
备用链接
主优先 / 备用优先
自动故障切换
```

可用性判断使用 DNS、TCP/TLS、服务器稳定 ID、证书/指纹和轻量 AssetLink 健康请求。Ping 仅作为可选诊断。

当前连接健康时不频繁切换；优先线路恢复后需要稳定窗口再回切。大文件使用 transfer ID、分块和断点续传跨端点继续。

## 4.4 内网、VPN 与公网

- 局域网 / 私有 VPN：完整能力，包括 UNC 和专业软件直接打开。
- 公网 HTTPS：受控浏览、预览、同步、上传、下载和服务端操作。
- 公网不暴露 SMB、PostgreSQL、DSM、缓存目录或 Provider 内部端口。
- 各资源库可选择仅 VPN、允许公网预览、允许公网下载或上传。

## 4.5 设备发现与配对

支持局域网发现、手动地址和一次性二维码。二维码只包含服务器身份、入口和短期配对码，不包含长期令牌。设备绑定后生成独立凭证，可单独撤销。

## 4.6 Windows 全局快捷面板

属于可选设备功能，默认关闭。支持按住约 350ms、双击组合键或普通热键。全屏、游戏、安全桌面和密码输入时默认禁用；支持进程黑白名单。误触只弹搜索面板，不自动发送、打开或执行物理操作。
