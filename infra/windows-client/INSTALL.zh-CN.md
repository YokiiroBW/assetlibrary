# 资产库 Explorer 只读浏览预览版

适用 Windows 11 x64。版本 0.3.0-preview.8。此预览包尚未签名；SHA256 校验只检查文件完整性，不代表发布者签名。请仅使用可信来源提供的完整安装包，不关闭系统安全保护。

图库工具栏显示当前页数量、已选数量及下一页提示；窄窗口会自动换行。部分 Windows 11 的系统底部状态栏仍会保留上个标准视图的计数，请以图库工具栏摘要为准。图库/列表与图片大小会跨目录和重新打开窗口记忆。

1. 将 ZIP **全部解压**到普通用户可读目录，保留 `payload` 与 `manifest.json`。
2. 双击 `AssetLibrary.Setup.exe`，按安装窗口提示安装。无需管理员权限。
3. 安装后在“连接设置”输入服务器 HTTPS 地址及账号。记住登录默认关闭。
4. 从 Windows 资源管理器左侧的“资产库”进入。资源库/目录右侧可切换“图库”和“列表”，调整图片密度；图片保持比例，目录优先，分页入口明确标为导航。

日常使用入口是原生资源管理器；后台会话会随当前用户登录启动。连接失效后请通过“连接设置”重新登录。

卸载：打开 Windows 设置 → 应用 → 安装的应用 → 资产库 Explorer 只读浏览 → 卸载。连接配置会保留，资产原文件不会被删除。若资源管理器仍占用组件，安装器会明确显示待清理版本；关闭资产库窗口后，再次双击解压包中的安装器可继续清理。安装器不会结束资源管理器进程。

更新：解压新版完整包并双击新版安装器。新版所有文件核验通过后才切换；旧版本保留到卸载时清理。同一版本的不同内容不能覆盖安装，请使用新的版本号。

图库只从服务端已授权的派生图片接口获取缩略图和大图，支持静态JPG/PNG/WebP。NAS同机图片服务已独立完成验收；其他未启用的服务、格式不支持或图片无效时显示明确提示，不会自行下载原件。

选中文件按Space、Enter或双击，在同一Explorer右侧打开最长边1600的预览；左右键或上一张/下一张切换当前页文件，Esc/返回恢复原选择和图库位置。Ctrl+Space保留选择切换。

大图内可滚轮缩放、左键拖动，按钮提供缩小/放大、适应和预览100%；双击在适应与100%间切换。键盘+/−缩放、0适应、1为100%，Shift+方向键平移。100%对应当前派生预览的像素，不是原件画质；显式缩放10%至400%。切图或退出即复位，缩放不保存为偏好，不增加图片请求。自动全库连续浏览、原件打开/编辑、时间轴与同步后续完善。

此版本是原生只读浏览、图库缩略图与连接会话，不代表完整 V0.3 的专业预览、设备配对、同步、传输或长期稳定性验证。G4 依用户要求豁免，未执行。
