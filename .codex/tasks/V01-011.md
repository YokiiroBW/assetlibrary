## 已批准的认证合同

- 首选身份源是应用本地账号；OIDC 不是当前运行依赖，但主身份验证结果与浏览器会话签发必须分离，后续 OIDC 适配器可复用同一会话、撤销和授权上下文。
- 账号登录名是 3–64 字符的小写 ASCII 标识符，只允许字母、数字、点、下划线和连字符；显示名继续由现有 `authenticated_principal` 承载，不把文件名或外部身份声明当作权限事实。
- 口令派生只使用仓库现有 .NET 标准能力：`PBKDF2-HMAC-SHA256`、每账号独立随机盐、至少 600,000 次迭代、32-byte 派生值并固定时比较；数据库不得保存明文、可逆口令或原始会话令牌。
- 新口令政策为 15–128 个有效 Unicode scalar，不要求字符组合、不禁止粘贴；常见/泄露口令拒绝属于后续账号预配/改密入口的必需门禁。本任务不提供可绕过该检查的生产预配入口。
- 未知账号、错误口令、禁用账号与陈旧凭据对调用方返回同一通用失败，不泄露账号存在性；未知账号也执行同成本虚拟派生。成功前不得签发会话。
- 每账号失败次数和下次允许时间持久化、原子更新，退避从 1 秒指数增长并封顶 5 分钟，不设置永久锁死；所有 I/O 有取消和 5 秒绝对截止时间。
- 浏览器会话令牌与 CSRF 令牌分别使用至少 256 bit CSPRNG；数据库只保存各自 SHA-256 摘要。会话固定 12 小时绝对寿命、30 分钟空闲寿命、凭据版本绑定、可立即撤销；每主体最多保留 20 个未过绝对期的会话。
- 会话校验返回现有 `AuthenticatedSubject` 和系统管理员事实；写请求必须额外验证与会话绑定的 CSRF 令牌。未来 HTTP adapter 只能用 `__Host-`、`Secure`、`HttpOnly`、显式 `SameSite` Cookie，且必须在 HTTPS 与严格 Origin/CSRF 检查下启用。
- 认证日志只记录稳定事件类型、结果分类和耗时，不记录账号名、显示名、口令、令牌、摘要、连接串、来源正文或数据库异常详情。

## 数据库与所有权

- 协调线程批准 V01-011 在没有其他迁移 writer 的独占窗口内追加一个连续生产迁移并更新 manifest；禁止修改既有 `0001`–`0009`。
- 新表和函数仅位于 `gateway_auth`，由 `assetlibrary_gateway_auth_owner` 拥有。`assetlibrary_gateway_auth_runtime` 不能直接读写表，只能执行列入 migration 的最终 `SECURITY DEFINER` 函数。
- 所有函数固定 `search_path`、参数化输入、长度/范围校验和明确 timeout 语义；运行时不能 `SET ROLE` owner、不能读取其他模块内部表，也不能新增跨模块写入。
- 生产账号预配、密码修改/恢复、数据库 LOGIN 角色和部署 secret 生命周期不在本任务内；集成测试只能在临时 PostgreSQL cluster 中由 owner 夹具写入测试凭据。

## 架构、复用与兼容

- `GatewayAuth` 是认证主体、本地凭据、会话、公开入口政策和授权编排的唯一 owner；LibraryStorage 仍唯一拥有资源库授权。
- 复用现有 `AuthenticatedSubject`、`authenticated_principal`、Npgsql 10.0.3、PostgreSQL 16 migration/role 机制、.NET `TimeProvider` 与加密标准库；不新增包、语言、框架、数据库或第二个 host。
- `Domain/Application` 不依赖 Npgsql、ASP.NET、文件系统或网络；数据库实现只在 `Infrastructure`。口令校验与会话签发分开，OIDC 后续只能从已验证的主身份进入同一 session issuer，不能复制会话政策。
- 新 migration 会推进 embedded manifest；V01-010 readiness 必须自然要求版本 10，旧/缺失/漂移数据库继续失败关闭。
- 凭据和会话查询按唯一登录名或固定 32-byte 摘要索引，单次 `O(log n)`；每账号会话清理最多处理固定 20 条，与 50 万资产无关。

1. 值对象与哈希：登录名规范、Unicode scalar 边界、超长/畸形输入、随机盐、固定算法/成本、错误/截断派生值拒绝、敏感类型字符串化脱敏。

3. 会话：原始 token 不落库、摘要查找、空闲/绝对过期、凭据版本变化、主体禁用、CSRF 匹配/不匹配、注销、20-session 上限和令牌碰撞失败关闭。
4. PostgreSQL 16：完整迁移、重复 apply、runtime 仅函数权限、owner 测试夹具、并发失败计数、登录成功原子复位/会话创建、撤销、重启持久化和索引计划。
