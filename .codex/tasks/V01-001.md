## 架构与复用说明

- 复用 M0-004 已验证的 .NET SDK `10.0.111` / runtime `10.0.11` 版本线；本机验证只使用忽略的任务沙箱，不安装到系统。
- `services/core-server` 与 `services/worker-supervisor` 只生成无入口点、无 I/O、无数据库和无网络行为的可编译程序集标记。
- 固定 C# 14、`net10.0`、Core Server 的 ASP.NET Core 10 framework reference、central package management 和 committed NuGet lock files；空 Worker 标记不提前引入 Hosting 包。
- 测试工具依赖仅限固定版本的 Microsoft.NET.Test.Sdk、MSTest.TestAdapter 与 MSTest.TestFramework；必须记录完整传递依赖许可证并运行漏洞检查。
- 不引用业务模块，不创建公共产品契约，不复制权限、路径、传输、同步、垃圾桶或 Provider 逻辑。
- `fast-merge` 必须实际执行锁定还原、格式、构建、测试、漏洞、许可证、复杂度、重复代码和敏感日志检查，且失败即阻断。
