## 架构与复用

- `LibraryStorage` 唯一拥有资源库权限档位和授权记录；无记录表示不可见。`GatewayAuth` 唯一拥有认证主体映射、公开入口政策及资源库授权编排。
- `AssetIdentity` 只发布 `present` 物理事实的只读投影；不向 GatewayAuth 暴露内容哈希、绝对根路径或内部扫描表。
- 跨 schema 只读通过迁移 7–9 明确授予的安全屏障视图和 `SECURITY DEFINER` 查询函数完成；没有跨 schema 写、外键或运行角色直读内部表。
- `GatewayAuth.Application` 只依赖模块公开 Contracts 与自身查询端口；Npgsql 仅存在于 Infrastructure，HTTP/React 不直连 PostgreSQL。
- API 复用生成的 AssetLink .NET SDK，Web 复用生成的 TypeScript SDK；操作 body 是 GatewayAuth 拥有的版本化 V0.1 只读应用合同，不建立第二套协议客户端。
- 目录浏览只返回资源库 + 规范相对路径，不泄露 NAS 绝对根。无权限与不存在使用同一外部结果，防止存在性侧信道。
- 物理事实搜索使用 PostgreSQL 16 的同库索引，不引入 SearchDedup 持久写模型；高级搜索仍由后续 `SearchDedup` owner 实现。
- Web 使用 Node.js 24 LTS、TypeScript 6.0.x、React 19.2.x；只增加 Vite 构建、Playwright 浏览器验证、Prettier 和大列表虚拟化所需的最小依赖。

## 行为与安全合同

- 匿名主体一律 `401`；无法解析的主体、请求、游标、页大小或操作一律结构化失败且不查询资产。
- 普通用户只能看见显式授予 `只读` 或更高权限的库；系统管理员可读全部库。撤权后新查询不得继续返回该库。
- 无权限库在库列表、目录浏览和搜索中都不可见；禁止通过状态码、库名、条目、总数、游标或日志泄露。
- 页大小默认 50、最大 100；数据库查询最多请求 101 项以生成下一游标，禁止 `COUNT(*)`、offset 分页或无界集合。
- 游标绑定操作和过滤条件，长度有上限；篡改、跨库、跨目录、跨搜索词复用均拒绝。游标不是授权凭证，每次翻页重新执行权限过滤。
- 搜索词 trim 后长度 2–200，只匹配文件名/规范相对路径并说明 `name` 或 `path` 命中；不查询文件内容、OCR、AI 或 Provider。
- API 默认超时不超过 10 秒并传播请求取消；Web 输入变化会 abort 旧搜索，陈旧响应不能覆盖新结果。
- Web 提供加载、空、错误、无权限/登录失效状态；桌面三栏，窄屏重排；列表只渲染可视区域，键盘焦点可见。
- 日志仅记录 request ID、操作、结果码和耗时，不记录主体标识、搜索词、真实路径、消息 body、凭据或完整异常正文。

## 性能边界

- 资源库、目录和搜索均使用稳定 keyset 游标；单页最多 100，数据库最多读取 101 条，不返回精确总数。
- 单目录 10 万项必须证明命中 `library + parent + state + sort key` 索引；名称/路径搜索必须证明命中 PostgreSQL 搜索索引。
- Web 使用窗口化渲染，不因当前页或后续追加导致 DOM 无界增长；换库、换目录和换搜索词会清空旧页并取消旧请求。
- 本任务的 10 万索引计划与浏览器窗口化证据不等于 50 万真实 NAS/P95 正式验收；后者仍由 scheduled-release 关闭。
