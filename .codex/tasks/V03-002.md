# V03-002 — Explorer 原生入口与进程外只读适配

Owner: windows-client-owner；分支 codex/v03-002-windows-native-read-client；V0.3 原生浏览预备交付。

## 目标

按用户最新纠正，Windows最终入口必须嵌入原生资源管理器，不能依赖独立客户端。协调批准采用 C++17/Windows SDK DefView+IShellFolder2，只通过进程外 C#14/.NET10 AssetHost 的授权只读投影适配 PIDL/属性/命令。先在test-only目录获得真实Explorer入口证据，再判断生产启用；不能以独立窗口或隐藏IShellBrowser替代真实嵌入。已开始的WinUI新草稿保存在自有.runtime，不进入交付diff。

## 必读与复用

已阅读 AGENTS.md、START_HERE、docs01/02/04/05/12/16/17/20/22/23、CODE_QUALITY、ADR0004/0012/0017、AssetLink README/read-only-trial-v1/web-interaction-v1、Windows视觉01/02/03。复用生成 .NET SDK envelope/uint64、核心授权查询和 packages/ui/workspace-theme.json。

## 所有权

允许 apps/windows-client/**、tests/windows-client/**、tests/windows-shell/**、本任务 task/handoff；禁止生产apps/windows-shell、核心/数据库/SDK/契约/根级版本锁/主题源与他人目录。共享门禁和ADR0018由V03-001协调。每轮只使用本任务单一HKCU CLSID，不覆盖已有/foreign状态，不改UAC/HKLM，不重启Explorer；有界通知和finally清理。Shell映射进程外传输投影，公开生成SDK保持权威，不复写核心规则。

## 约束与验收

HTTPS origin 严格验证；禁止重定向；指纹限定叶证书、单源、主机名与有效期；凭证不持久化。401/403/404 清理敏感状态；取消/导航代际防止旧响应覆盖；每页100且内存仅持有当前页。读请求有超时/响应上限。测试只用隔离样例。提供 Release 构建、自包含包、协议/故障测试、原生窗口验证、漏洞/许可证/体积、最终 diff 审查和标准交接 commit。不关闭 Alpha/完整V0.3/Explorer/写入门禁。
