# TS-099 内部任务包

产品：AssetLibrary。归属模块：`OperationTrash`（本卡由本任务独占其 `MediaPackage*` 只读预检增量）。

## 范围

资产成品包**只读预检**：对 staging 成品包（`stagingRoot/<staging_ref>` 直接子目录 + `manifest.json`）
做完整校验并产出只读报告——清单严格性、身份、布局、文件集、路径边界、字节预算、目标容量与冲突、
授权与 scope 复核。**不含**搬运/发布执行、目标目录创建、HTTP 入口、数据库写入、NAS 访问。

根 `contracts/media-package/candidate-v1` 已特批作为本卡候选输入（`task_fixture_only`），
**不是**生产发布合同；该目录全程只读。

## 复用点

`RelativeAssetPath`、`LibraryId`、`CanonicalLibraryRoot`、`Sha256Digest`、`MediaPackagePathBoundary`、
`MediaPackageFileHasher`（各自单一所有者已发布版本）；`OperationTrash` 既有权限、锁、空间与审计语义。

## 完成标准

1. 预检全程零写入：不创建目标目录、不写库、不写审计文件；报告恒 `grants_file_operation=false`。
2. 未授权调用方零 I/O；scope 在运行中失效必须报 `scope_changed`。
3. 冻结错误词表（22）与 `unverified` 清单（7）逐字冻结、顺序即契约；报告最多 100 条并置 `truncated`。
4. 原始清单路径先词法拒绝再构造 `RelativeAssetPath`；大小写折叠碰撞、重解析点与逃逸路径全部拒绝。
5. 清单严格性：重复键、非原始整数词法、非法 UTF-8、BOM、超预算全部拒绝；解析只用 `System.Text.Json`。
6. `expected_digest` 用原始字节 SHA-256，夹具锁定摘要用 LF 归一化，两者不得混用。
7. 依赖方向 `Infrastructure -> Application -> Domain`，`Domain` 不含 `System.IO`。
8. Release 构建、架构门禁、源码重复检查与格式检查全绿；隔离测试实际执行。
