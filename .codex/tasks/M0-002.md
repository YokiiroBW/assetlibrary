## Required outcomes

1. 在 Spike 目录提供最小 C++/WinRT/COM 源码与可重复构建入口，边界只包含命名空间、导航、最小 IShellView 桥接和进程间通信；重型 UI、网络、哈希、Provider 与媒体解码均留在进程外。
2. 提供最小进程外 AssetHost 测试替身与有界 IPC。Host 不存在、崩溃、超时或返回无效数据时，Shell 侧必须快速失败并显示可恢复状态，不得同步无限等待。
3. 提供仅当前用户范围的安装、注册、验证、卸载脚本；脚本必须幂等，并能在失败后恢复到未安装状态。禁止系统级安装和静默覆盖既有注册项。
4. 提供自动化静态/契约检查，验证禁止依赖、IPC 超时、注册/卸载对称性和测试包结构；这些检查必须能在当前 Linux 协调环境运行。
5. 提供真实 Windows 11 验证说明，至少覆盖构建、注册、导航、自定义右侧视图、Host 缺失、Host 崩溃、IPC 超时、卸载与 Explorer 恢复。提供可配置 8 小时 soak 入口，但未执行时必须明确记为跳过。
6. 将观察结果、环境版本、失败模式、是否建议继续采用 C++/WinRT + COM + 进程外 Host 写入 Spike 记录；该建议供 M0-009 裁决，不得直接冻结正式架构。
