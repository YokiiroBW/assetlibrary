## 完成标准

- 新增独立命令行故障 host，显式 `--execute` 才能占用冻结的 SID/session 管道；同 TokenUser SID DACL、拒绝远程、first-instance，验证客户端 session，不抢占现存 host。
- 支持 silent/超时、invalid-version/错误帧、partial-frame 模式；读取实际请求 ID，正确模式只用合成数据。崩溃应是自有故障进程在读取请求后的明确异常退出，可标记 `--mode crash`，不得终止其它进程。不得读私密 profile、连接服务端或资产目录。
- 有固定最长期限（上限 120 秒）、有界连接数和 I/O；支持正常停止（进程自有 stop-file 或事件），清理 worker/handles。停止路径不把请求正文或身份秘密写日志。
- JSONL 仅输出模式、PID、请求计数、单调时钟事件/耗时、正常停止或预期异常退出。退出/断连后能由新 host 占用同一管道。避免快速空转和无限日志。
- 增加必要自动用例，验证真实故障工具被 Shell 的现有客户端识别为预期状态、有界返回、停止/超时后可重连及拒占用，不把独立 mock 测试算真实 Explorer 验收。
- 写清楚 GUI 如何启动/等待就绪/注入故障/停止；门禁原标准不变，G2 不需要所有 COM 对象即时释放；泄漏与取消时间属于 G3。不能自行关闭门禁。
- 最终 diff 审查、严格 Release 构建、受影响 CTest、仓库架构/契约验证；提交代码和准确 architecture_review 交接。新增命令登记 README/CMake。
