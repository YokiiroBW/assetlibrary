## 架构与复用说明

- 生成器复用 M0-003 已验证的 JSON Schema 合同与 uint64/evolution 规则，使用 Python 标准库，不引入生成框架或第二份手工模型来源。
- 三端生成物只定义 wire DTO、消息分类、JSON 往返与受检 uint64 转换；不引用任何业务模块，也不建立客户端传输层。
- .NET 复用 V01-001 的固定 .NET SDK `10.0.111`、C# 14、`System.Text.Json`、中央测试包版本和 NuGet 锁定/许可证/漏洞门禁，不新增运行时 NuGet 包。
- TypeScript 固定 TypeScript 6.0.x 与 Node.js 24 LTS，仅使用构建期 TypeScript 和 Node 内置测试能力；无运行时 npm 依赖。
- Kotlin 固定 Kotlin 2.3.x、JDK 21 LTS、Gradle 9.3.x 与 `kotlinx-serialization-json`；只使用 JSON tree API 保存完整未知字段，不启用 Android 或 Compose。
- 每个 target 提交 `.contract-source.sha256`，根生成清单记录合同摘要、schema shape 与输出摘要；`--check` 对缺失、手改、过期及额外生成文件失败关闭。
- `fast-merge` 必须实际执行生成漂移检查、跨语言等价测试、三端编译/单测、依赖锁/校验/审计/许可证、体积与敏感日志门禁；不得 `continue-on-error`。
