# 合并清单

- 任务依赖均已完成或明确豁免；
- commit 与交接文件一致；
- 共享契约变更已批准；
- 单元、集成、契约和故障恢复测试通过；
- 数据库迁移顺序明确；
- 无凭证、真实路径、用户数据或大型缓存被提交；
- 主分支构建通过；
- 更新 project-state 与 task-registry；
- 删除或保留 worktree 的决定已记录。
- 架构边界、循环依赖和语言预算检查通过；
- `architecture_review` 已由主协调线程核对；
- 未新增 God Service、万能共享目录或重复核心业务逻辑；
- 新重大依赖与技术栈均有批准 ADR 和退出策略；
