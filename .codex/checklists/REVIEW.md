# 代码评审清单

- 是否符合已确认需求，而非自行扩展范围？
- 是否破坏物理目录权威原则？
- 是否存在静默覆盖、删除或错误重指向？
- 是否正确处理权限、保护、垃圾桶和审计？
- 是否支持取消、超时、恢复和幂等？
- 是否会阻塞 Explorer 或把重型处理放入 Shell 进程？
- 是否对 50 万资产使用分页、索引或虚拟化？
- 是否在没有 AI / Provider 时安全降级？
- 是否只使用隔离测试目录？
- 是否提供测试与标准交接？
- 是否通过 `.codex/checklists/ARCHITECTURE_REVIEW.md`？
- 是否复用统一 Application 用例，而非在入口层复制业务逻辑？
- 是否遵守模块数据所有权，未跨模块写表或引用内部实现？
- 是否引入未经 ADR 批准的语言、框架、运行时或重大依赖？
- `architecture_review` 是否与实际 diff 和测试一致？
