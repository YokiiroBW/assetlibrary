## 完成内容与关键决策

- 既有 AssetLink 客户端现在对 `fetch` 与响应正文读取共同施加 5 秒截止时间。超时中止连接并显示可重试错误；调用方取消保留原始取消原因，已取消调用不会发送请求。成功、失败和取消都清除计时器及调用方监听器。
- 请求错误处理保留已经收到的失败 HTTP 状态。401/403/404 的 HTML、畸形错误字段或挂起正文不能再退化为无状态网络错误并保留旧页；有效协议错误继续使用服务端错误信息。
- 三个分页 Hook 共用 `failedPage`：401/403/404 清除当前查询的旧条目和游标；503 等暂时故障保留已有可读快照并显示错误。资源库列表被拒绝时同步停用依赖的浏览与搜索，所选详情也隐藏并清空。
- 登录失效后通过 React 工作界面重新挂载恢复连接，重建客户端、资源库、目录、搜索和选择状态；上一身份的选择不会在重新认证后出现。卸载时中止当前在途请求，包括后续分页请求。
- 浏览器回归由 6 个扩展到 22 个。新增真实 loopback HTTP fixture 验证无响应头、挂起正文、物理连接关闭、提前取消和重试；保留已有桌面分页/虚拟化、窄屏重排、导航和陈旧响应回归。

- 修改仅属于 Web 只读适配器；网络仍集中在唯一 AssetLink `fetch` 中，使用既有生成 TypeScript SDK 编解码。
