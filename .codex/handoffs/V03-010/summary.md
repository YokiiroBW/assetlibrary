# V03-010 AssetHost 交接

已实现受控、进程外 Windows AssetHost。复用既有 HTTPS/认证/生成 SDK/分页适配，将真实授权库和目录投影成不透明令牌页面；Shell 不接收 URL、凭据、Core ID 或物理路径。支持原生刷新、文件夹、只读文件/链接显示、100 项加显式下一页。

本地 byte pipe 由实际 TokenUser SID 专属 DACL、first-instance 预留、远程拒绝、会话检查保护。保留 4 个实例；HTTP 永不在 pipe handler 上等候，最多 2 个查询、64 页面、8192 令牌；连接含排空等待 500 ms。成功页 5 秒后不回放，失败退避 1 秒。401/403/404/会话到期取消并清空身份快照，410/容量上限换 epoch 后重开根，晚到结果不能复活旧数据。

验证通过：普通 Windows 54 项（其中新 Host 33），真实 Core/PostgreSQL 2 项（其中新 Host 1），locked restore、格式、Release 构建 0 警告/错误，451 文件源码策略，4 项目/15 锁定包依赖审计。真实 Core 测试含跨页、相册→夏日→文件和无权限账号。曾发现的 malformed packet listener 异常分类缺陷已被反例测试捕获并修复；首次 live 失败是测试误判两层支架目录为一层，修正后验证真实两层。

分支 `codex/v03-010-explorer-assethost`；物理 worktree 保留 `V03-009` 路径。基线 `7016377`，共享契约由主协调后续澄清（实际任务号、framing、410、100+one）不在本分支修改。合入顺序：V03-005 契约 → 本 Host 与 V03-006 Shell → 主协调互通和实际 Explorer 统一验收。

复用和影响：无新外部依赖/框架/主语言，未改 Core adapter。适配器只调用公开应用端点，无数据库/核心内部访问、业务权限复制或原资产写入。库规模 50 万时只请求当前 Core 索引页，Host 固定数量快照/令牌、每页 O(100)，不会加载全库。修改既有 LiveCoreTests 仅复用获准的环境检查，无测试凭据或行为变更。

仍需主协调验证实际 C++ 进程互通、原生 Explorer 可见导航、Host 缺失/重启及文件哈希和注册清理。未声明生产 Shell、安装包、WinUI 登录设置、预览/打开、推送失效或 G2/G3/G4 完成。Host 测试已关闭随机后缀管道；本任务从未占用默认端点或操作 GUI/注册表/服务支架。
