# V03-008 实施清单（冻结契约前）

2026-09-08；以下保留基于70ce45c的冻结前准备记录。随后已合入协调38aedca契约并在4e633e8完成实现；当前状态与实际验证以summary.md/tests.md为准。

## 已核查的调用链

- `SessionGate` 以会话 generation 挂载工作区；退出、跨标签身份变化、BFCache 复核会卸载。`useSession` 在普通 focus/visibility 复核期间尚保留页面，图片需补前台复核期间的遮蔽/失效边界。
- `ReadOnlyWorkspace` → `EntryCollectionPage` → `VirtualEntryList`；每页 100 条，TanStack 虚拟行含 overscan（网格 3 行、列表 8 行）。挂载不等于真实可见，应通过列表滚动容器的相交范围决定图片订阅。
- `useEntry` 重新请求稳定 library/entry ID 的索引详情，代际和 AbortSignal 防止旧响应覆盖。文件双击/Enter 当前设置 route.entryId；宽屏显示侧栏、窄屏 Modal。继续复用历史/深链/恢复，不创建第二路由系统。
- Space 当前切换选择，与 docs12 Quick Look 不符。普通 Space 改为临时预览、不改变 URL/history；组合键与选择控件保留多选。Escape 关闭且焦点回到原条目；原条目已卸载时回列表的可操作焦点。
- `AssetLinkClient.transport` 是唯一允许 fetch 的位置，使用同源 Cookie、内存 CSRF、5 秒总期限；生成 SDK 负责 control envelope。预览二进制仍须复用这一传输入口，保持现有 JSON 消费者兼容。

## 集中实现范围

1. 按已提交冻结文件增加明确请求/响应类型、成功 MIME/尺寸/字节校验、有限流读取以及关联校验。不得猜 endpoint、根据扩展名断言真实格式、下载原图或接受服务返回的任意 URL。
2. 在工作区实例内管理有界派生图片请求与生命周期；仅可见缩略图和当前预览订阅，离屏/切库/筛选/关闭时取消，晚到结果不得创建可见资源。总并发、队列、Blob 字节和解码像素均有上限，具体数值跟随冻结规格。无需持久缓存或离屏照片存储；Object URL 只在活动消费期存在，释放时清空 src 并 revoke。
3. 默认单击保留文件信息；打开进入基础图片预览并保留详情与位置操作。未知、离线、损坏、超限和服务不可用保持 L0 可读及准确提示；不声称原图色彩/原始分辨率无损。
4. 401 立即退出工作区；403/404 清空相关图片并触发权限复核，HTTP 拒权不等坏正文或流结束。切身份、退出失败、BFCache/前台复核和页面卸载不保留旧画面/URL/待处理响应。
5. 复用语义 CSS、现有 Modal 和窄屏布局，覆盖浅深色、390/1440 视口、放大与键盘。需要缩放时只做展示，不混入编辑或写操作。
