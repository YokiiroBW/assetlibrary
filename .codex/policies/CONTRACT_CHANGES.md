# 共享契约变更流程

1. 工作线程不得直接随意修改共享契约。
2. 先提交 Contract Change Proposal，说明动机、兼容性、迁移、影响客户端和测试。
3. 主协调线程或契约所有者批准后，创建独立契约任务。
4. 契约变更必须带版本、向后兼容说明和消费方测试。
5. 旧客户端不能因未知字段或新 Provider 能力整体失效。
6. 数据库迁移必须可重复执行、可检测状态，并在执行前自动备份。
7. 契约是跨端复用的唯一来源；生成的 .NET、TypeScript、Kotlin SDK 不得手工修改。
8. 契约变更必须通过消费者测试，并检查是否导致入口层复制业务规则。
9. 契约所有者同时维护统一错误码、弃用期和 capability negotiation。
