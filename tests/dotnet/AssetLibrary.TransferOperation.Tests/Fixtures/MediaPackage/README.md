# media-package 候选清单：TS-099 任务输入

状态 **task_fixture_only**；本目录不是生产发布合同，`runtime_routes_enabled=false`。由媒体协调者冻结，DSH 只读，不修改。用于 TS-099 的隔离只读预检与后续生产者/消费者评审；G-PUBLISH 尚未通过，TS-094 不能据此直接开放发布。

本目录只有一个能力：描述已准备在授权入站包目录里的有限文件集。它不授权传输、写目标、创建资产、改变库权限或刷新媒体服务器。真实上游、格式可播放性、图片可解码性和媒体服务器识别均未验证。

`schema.json` 表达形状；`semantics.md` 是跨字段/字节/路径/预算的同等权威。`examples.json` 提供有效清单的确切 base64 字节、SHA256 和合成文件内容；`negative-examples.json` 给最小失败输入。合成视频/图片是明示测试字节，不能声称真实媒体。NFO/source.json 由已集成 TS-090 `b2132836ab3b3d026512b974d93406f58a9219aa` 的纯函数生成，不运行网络或真实源。

`manifest.json` 锁定本目录 UTF-8 文件 LF 归一后的 SHA256；其自身摘要由任务派发记录绑定。清单自身的 digest 则是**请求携带的原始字节** SHA256（不做 LF 归一、不重序列化），两个摘要用途不可混用。

后续发布至少补：真实凭据/写入授权、入站交接原子性/对账、持久幂等与租约、确认摘要、重启恢复、强路径句柄、跨卷发布与索引补偿，以及平台生产者/资产消费者联合样例。到时以独立版本发布，不静默把本候选升级成可执行合同。
