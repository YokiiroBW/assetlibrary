The driver accepts tool locations only. It creates its own temporary loopback PostgreSQL cluster, applies the current production migration manifest, creates six restricted module logins, starts the real `TrialHostFactory` on pinned HTTPS and scans 138 synthetic originals. It never accepts a live server, database, NAS or credential. A static test HTML shell satisfies the Host configuration; this is not browser UI evidence. The existing HIBP test responder is the sole external authentication substitute.

The aggregate exercises all five operations, 100+37 paging, Chinese search, two independent service principals/library scopes, rejected mixed/browser authentication, read-only dispatch, browser CSRF/Origin/session compatibility, library revocation on next page/get/list/search, credential rotation/revocation/disable, expiry and Host restarts. Expiry uses a two-second credential through the public Application use case; the operator default is independently asserted as 30 days.

After Host disposal, the driver uses the restricted LibraryStorage login to verify failed batches preserve existing permissions, ordinary/admin/disabled subjects cannot be granted, disabled subjects can be revoked, matching retries create one audit, conflicting retries are rejected, stale grant retries cannot undo a later revocation, and direct ACL writes are denied. It then checks database least privileges and lifecycle authentication counts across PostgreSQL restart and verified migration-tool backup/restore. An injected next migration fails atomically; the real manifest remains usable. Original SHA256/mtime checks are mandatory. The driver checks database/role/cluster cleanup before writing a successful `.runtime/ts063-service-*/acceptance.json`. Raw credentials are never printed by the test helpers; private transient settings and backups remain in the disposable temporary root. Test output and TRX stay under the ignored task runtime.

This is AssetLibrary-only verification. It does not establish Platform consumption, the proposed 1MiB platform response limit for all possible data, real-browser UI, NAS, production deployment, 500k query plans or physical asset write capabilities. The fixture's 1MiB response check is only a consumer test budget.
