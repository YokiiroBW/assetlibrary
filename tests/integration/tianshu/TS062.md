# TS062 公开端口验证

工作目录固定为 TS062 AssetLibrary 根。使用 Python3.12+与 global.json 指定的 SDK10.0.111；所有缓存归本任务，不接受服务器/数据库/凭据参数。

```powershell
$env:DOTNET_CLI_HOME = Join-Path (Get-Location) '.runtime/ts062-dotnet'
$env:NUGET_PACKAGES = Join-Path (Get-Location) '.runtime/ts062-nuget'
dotnet restore tests/dotnet/AssetLibrary.WebGateway.Tests/AssetLibrary.WebGateway.Tests.csproj --locked-mode
dotnet build tests/dotnet/AssetLibrary.WebGateway.Tests/AssetLibrary.WebGateway.Tests.csproj --configuration Release --no-restore
python -I -B tests/integration/tianshu/verify_service_read.py --dotnet <exact-dotnet.exe>
```

脚本比较 TS060 HTTP 基线的 services/packages/database/contracts/SDK配置/原生夹具及 .NET 测试输入，确认可继承历史HTTP证据；不重新启动TS060实例。然后运行七个现有测试类，真实调用公开 Application/AssetLink 端口，query/ClaimsPrincipal是明确测试替身。覆盖主体来源、分页、越界结果、搜索、认证拒绝、错误与取消/超时；不能证明服务凭据HTTP、实时PG撤权或真实平台接入。

TRX仅留本任务 `.runtime/ts062-port-results/ports.trx`，提交脱敏 `.codex/handoffs/TS-062/port-evidence.json`。已有结果时拒绝覆盖，成功后不重复运行。没有启动PG/监听/真实资产任务，无新数据库或凭据可复用。

未来服务实现验收矩阵见 `docs/integrations/tianshu/service-read-plan.md`，原浏览器HTTP入口和真实清理边界见本目录 README。当前只在继承输入不变时沿用TS060证据，不把继承算成本轮新HTTP成功。
